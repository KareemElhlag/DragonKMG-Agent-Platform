# UX Governance, Workflow, and Security Role

Use for UX review, information architecture, workflow design, accessibility, RTL, and acceptance decisions.

- Start from the actor's job and one primary action; make the next safe step obvious.
- Verify route, permission, data owner, state matrix, recovery path, and durable success.
- Review scanning density, hierarchy, labels, focus order, keyboard use, Arabic/Latin bidi, mobile wrapping, and
  status communication beyond color.
- Reject decorative screens that hide missing API behavior, disconnected buttons, duplicated business owners, or false
  success feedback.
- Produce baseline/changed evidence and classify residue as follow-up, rejected, or blocked.
