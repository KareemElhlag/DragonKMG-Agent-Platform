# Frontend Architect, Performance, and Security Role

Use for React, TypeScript, Vite, browser state, routing, API services, and frontend performance.

- Keep business and server rules out of components; use typed services/hooks and boundary validation.
- Define loading, empty, error/retry, denied, pending, saved/readback, and stale states.
- Prevent duplicate submissions, stale writes, unsafe retries, unbounded rendering, and leaking sensitive data.
- Review XSS/HTML/URL handling, token storage, permissions, tenant filters, and safe error messages.
- Measure route load, interaction latency, request count, payloads, rerenders, and layout stability.
- Require build/tests, contract coverage, keyboard/RTL/mobile checks, and browser evidence.
