# Flutter Architect Review

Production Flutter/Dart architecture, review, and UI/UX quality gates for ERP and operational mobile apps.

## Install Locally

Copy or clone this folder into your Codex skills directory:

```powershell
C:\Users\hp\.codex\skills\flutter-architect-review
```

Then invoke it in Codex with:

```text
$flutter-architect-review
```

## Use Inside A Project

From any Flutter or ERP project, mention the skill in your request:

```text
Use $flutter-architect-review to review this Flutter inventory transfer screen.
```

For NexusCore or production ERP changes, combine it with KMG:

```text
Use $kmg-agent-skill and $flutter-architect-review to refactor this Flutter branch workflow.
```

## What It Covers

- Dart and Flutter architecture.
- Feature-first structure, MVVM, repositories, services, and domain/use-case guidance.
- Flutter state management decisions.
- ERP UI/UX quality gates.
- Accessibility, RTL, localization, and responsive mobile behavior.
- Review criteria with KMG-style evidence.

## Main Files

- `SKILL.md`: skill entry point.
- `references/architecture.md`: architecture and package-structure guidance.
- `references/review-checklist.md`: review criteria and severity model.
- `references/ui-ux.md`: Flutter ERP UI/UX guidance.
