# إدارة عمر سياق الجلسات

تستخدم المنصة مخطط `ContextGarbageCollector` محليًا لتقليل حجم سجل السياق دون استدعاء النموذج أو إرسال البيانات إلى مزود خارجي. لذلك لا توجد تكلفة توكن أو تكلفة شبكة لعملية الجمع نفسها.

المخطط لا يحذف مباشرة؛ يعيد قائمة معرفات لتطبيقها داخل معاملة قاعدة بيانات. يحمي دائمًا الرأس الحالي، والعُقد المثبتة، وكل سلسلة الآباء اللازمة لإعادة بناء Checkpoint. يطبق `MinimumAge` قبل أي حذف، ثم حدود عدد العناصر والحجم لكل جلسة. النتائج حتمية ويمكن اختبارها وإعادة تشغيلها بأمان.

## التشغيل مع ملخصات الجلسات

كل Snapshot أو Checkpoint يحمل `ParentId` و`SessionId` ووقت الإنشاء والحجم. عند إنشاء ملخص جديد يصبح رأس السلسلة، ويظل التاريخ الأصلي قابلًا للاسترجاع. يمكن تشغيل الجمع في مهمة دورية منخفضة الأولوية أو بعد حفظ Checkpoint، مع تنفيذ الحذف في معاملة واحدة وبعد نجاح الحفظ الجديد.

## سياسة افتراضية مقترحة

```json
{
  "minimumAge": "7.00:00:00",
  "maxArtifactsPerSession": 64,
  "maxBytesPerSession": 4194304
}
```

الجمع محلي deterministic ولا يستخدم `IModelGateway`. هذا يسمح بتشغيله في CLI أو API أو Worker بنفس النتيجة، ويمنع تشغيل كل الوكلاء لمجرد تنظيف السياق.
