# دورة الأسئلة التفاعلية

تُستخدم الأسئلة عندما يحتاج الوكيل قرارًا صريحًا من المستخدم قبل متابعة سير العمل.

## دورة الحالة

`Pending → Answered → Workflow Resume`

أو `Pending → Expired/Cancelled` عند انتهاء المدة أو إلغاء الطلب.

كل سؤال محفوظ في `interactive_questions` ويرتبط بالجلسة، وسير العمل، والوكيل، والخيارات، والإجابة ووقت الانتهاء.

## القواعد

- لا تُقبل إجابة خارج قائمة الخيارات المحفوظة.
- لا يمكن الإجابة على سؤال مغلق أو منتهي.
- السؤال مرتبط بالجلسة ولا يمكن استخدامه من جلسة أخرى.
- الإجابة لا تمنح صلاحيات أدوات ولا تتجاوز الموافقات.
- لا يستأنف سير العمل إلا بعد حفظ الإجابة والتحقق منها.

## API

- `GET /api/sessions/{id}/questions`
- `POST /api/sessions/{id}/questions/{questionId}/answer`

واجهة الجلسة تعرض السؤال المعلّق كبطاقة خيارات، وتخفيه بعد الإجابة. الاستئناف الفعلي للمرحلة التالية يعتمد على ربط WorkflowRun بمحرك الاستئناف في المرحلة التالية.
